ClauJev é um plugin do Claude Code que põe um segundo modelo, de outra empresa, para conferir o trabalho do Claude. Antes da resposta chegar a você, o Jev, da TypeSafe AI, compara o diff do git com o que o Claude diz ter feito. Se algo ficou pela metade, o Claude volta e termina.

ClauJev is a Claude Code plugin that puts a second model, from another company, on Claude's work. Before the reply reaches you, Jev, from TypeSafe AI, compares the git diff with what Claude says it did. If something is half done, Claude goes back and finishes.

O que já existe e o que é novoWhat already exists, and what's new

O Claude Code já tem hooks, permissões e plugins de segurança. O ClauJev não refaz isso. Ele entra onde essas ferramentas param: saber se o trabalho foi mesmo feito, sem perguntar ao próprio Claude.

Claude Code already has hooks, permissions and safety plugins. ClauJev doesn't redo them. It steps in where they stop: knowing whether the work was really done, without asking Claude itself.

O que não é novo. Para bloquear push, rm -rf e afins, as permissões do Claude Code e plugins como o safety-net já resolvem. Para regras por padrão de texto, há o hookify. O ClauJev traz uma guarda local simples para você não ficar descoberto, mas não é por ela que vale instalá-lo.

What isn't new. To block push, rm -rf and the like, Claude Code's permissions and plugins such as safety-net already do the job. For pattern-based rules there's hookify. ClauJev ships a simple local guard so you're not left exposed, but it isn't the reason to install it.

Onde o Jev entra no turnoWhere Jev steps into a turn

O ClauJev escuta os hooks do Claude Code. Em cada um, monta um resumo pequeno do momento, pergunta ao Jev e devolve ao Claude uma ação ou nada. O começo e o fim do turno são o que ele traz de novo; o meio é o básico.

ClauJev listens to Claude Code's hooks. At each one it builds a small summary of the moment, asks Jev, and hands Claude an action or nothing. The start and end of the turn are what it brings that's new; the middle is the basics.

  1. UserPromptSubmit

    Você pedeYou ask

    novonew

    Triagem. Qual o tamanho da mudança e quanta investigação o pedido exige? Com o mod, o ClauJev pergunta se você quer mudar o esforço, de low a xhigh, antes de começar. Se o pedido estiver vago demais, o Claude é avisado.

    Triage. How big is the change, and how much investigation does it need? With the mod, ClauJev asks whether you want to change the effort, low to xhigh, before it starts. If the request is too vague, Claude is warned.

  2. PreToolUse

    O Claude roda um comandoClaude runs a command

    básicobasics

    Guarda. Push, merge e reset --hard pedem confirmação por uma regra local, como em qualquer plugin de segurança. O Jev só entra no que regra não pega: um script que migra o banco, um deploy, uma credencial no comando.

    Guard. Push, merge and reset --hard ask for confirmation by a local rule, like any safety plugin. Jev only steps in where no rule can: a script that migrates the database, a deploy, a credential in the command.

  3. PostToolUse

    O Claude editaClaude edits

    básicobasics

    Regras. Cada edição é conferida contra regras que você escreve em texto comum. Como quem lê é um modelo, vale até para regras de sentido, como "erro de API sempre tratado".

    Rules. Each edit is checked against rules you write in plain words. Since a model reads them, even rules about meaning work, like "API errors are always handled".

  4. Stop

    O Claude diz "pronto"Claude says "done"

    novonew

    Conferência final. Um segundo modelo, independente do Claude, lê o diff (inclusive o que foi editado pelo shell), os comandos e a resposta. Se algo ficou pela metade, o Claude volta antes de você pedir.

    Final check. A second model, independent from Claude, reads the diff (shell edits included), the commands and the reply. If something is half done, Claude goes back before you ask.

Subagentes também. Tarefas simples vão para um modelo menor e mais barato, e um relatório de subagente que diz ter feito algo que não fez é apontado.

Subagents too. Simple tasks go to a smaller, cheaper model, and a subagent report that claims work it didn't do gets flagged.

Sinal, não sentençaA signal, not a verdict

Cada resposta do Jev é uma probabilidade, e cada pergunta tem dois limiares que a dividem em três faixas. Só a faixa alta age.

Every Jev answer is a probability, and every question has two thresholds that split it into three bands. Only the high band acts.
