ClauJev é um plugin do Claude Code. Em cada passo do Claude, ele faz perguntas curtas ao Jev, o modelo de julgamento da TypeSafe AI, e avisa quando um comando é perigoso, um pedido está vago ou o trabalho ficou pela metade.

ClauJev is a Claude Code plugin. At each step Claude takes, it asks Jev, TypeSafe AI's judgment model, a few short questions, and speaks up when a command is risky, a request is vague or the work is half done.

Na práticaIn practice

O Claude tinha permissão para qualquer comando git. Mesmo assim, antes do push forçado sobre o main, o Jev marcou efeito destrutivo e o Claude Code parou para perguntar.

Claude was allowed to run any git command. Still, before the force push over main, Jev flagged a destructive effect and Claude Code stopped to ask.

[Jev] Command flagged: destructive effect (p=0.92)

Um turno do Claude, quatro pontos de checagemOne Claude turn, four checkpoints

O ClauJev escuta os hooks do Claude Code. Em cada um, monta um resumo pequeno do momento, pergunta ao Jev e devolve ao Claude uma ação ou nada.

ClauJev listens to Claude Code's hooks. At each one it builds a small summary of the moment, asks Jev, and hands Claude an action or nothing.

  1. UserPromptSubmit

    Você pedeYou ask

    Triagem. É pergunta, mudança pequena, grande ou vago demais? O Claude recebe a dica e um esforço de low a xhigh.

    Triage. A question, a small change, a big one, or too vague? Claude gets the hint and an effort from low to xhigh.

  2. PreToolUse

    O Claude roda um comandoClaude runs a command

    Guarda. Push forçado, reset --hard, migration, deploy? Você confirma antes. Comandos só de leitura nem chamam o Jev.

    Guard. A force push, reset --hard, a migration, a deploy? You confirm first. Read-only commands don't even call Jev.

  3. PostToolUse

    O Claude editaClaude edits

    Regras. Cada edição é conferida contra regras que você escreve em texto comum, como "não usar any".

    Rules. Each edit is checked against rules you write in plain words, like "never use any".

  4. Stop

    O Claude diz "pronto"Claude says "done"

    Conferência final. O Jev lê o diff, os comandos e a resposta. Se algo ficou pela metade, o Claude volta antes de você pedir.

    Final check. Jev reads the diff, the commands and the reply. If something is half done, Claude goes back before you ask.

Subagentes também. Tarefas simples vão para um modelo menor e mais barato, e um relatório de subagente que diz ter feito algo que não fez é apontado.

Subagents too. Simple tasks go to a smaller, cheaper model, and a subagent report that claims work it didn't do gets flagged.

Sinal, não sentençaA signal, not a verdict

Cada resposta do Jev é uma probabilidade, e cada pergunta tem dois limiares que a dividem em três faixas. Só a faixa alta age.

Every Jev answer is a probability, and every question has two thresholds that split it into three bands. Only the high band acts.

  • Começa só observando.Todo hook vem em observe: registra e não interfere. Leia o relatório e ligue o enforce onde fizer sentido.
  • Starts by watching.Every hook ships in observe: it logs and stays out of the way. Read the report, then turn on enforce where it makes sense.
  • Nunca apaga nem desfaz nada.Um alarme falso custa uma frase do Claude, não o seu trabalho.
  • Never deletes or undoes anything.A false alarm costs one sentence from Claude, not your work.
  • Nunca quebra a sessão.Se a API cair, vai para o log e o Claude segue. Em enforce, comandos claramente destrutivos ainda pedem confirmação, por uma checagem local.
  • Never breaks the session.If the API is down, it goes to the log and Claude carries on. In enforce, plainly destructive commands still ask, from a local check.

O que sai da sua máquinaWhat leaves your machine

Jev never sees the whole conversation, only the summary built for each question, with keys and tokens removed.

InstalarInstall

O ClauJev é 100% gratuito. Você precisa do Claude Code e de uma chave da TypeSafe AI, que cobra o uso da API do Jev.

ClauJev is 100% free. You need Claude Code and a TypeSafe AI key; TypeSafe AI bills Jev API usage.

  1. Instale o plugin no Claude CodeInstall the plugin in Claude Code

    /plugin install claujev --marketplace Civalski/claujev

  2. Cole a chave da TypeSafe AIPaste your TypeSafe AI key

    É a única coisa que a instalação pede. Depois, reinicie o Claude Code.

    It's the only thing the install asks for. Then restart Claude Code.

  3. Siga a configuração guiadaFollow the guided setup

    Na primeira conversa, o Claude oferece configurar idioma, modo e recursos. Para mudar depois, rode /claujev:configure.

    In the first conversation, Claude offers to set language, mode and features. To change them later, run /claujev:configure.
